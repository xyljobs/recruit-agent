# 外部招聘平台浏览器自动化：默认禁用

本目录曾包含针对第三方招聘平台的实验性浏览器自动化说明。该能力不属于 GOAI 参赛交付，也不是默认产品能力。

## 当前约束

- `.env.example` 默认 `ENABLE_BOSS_SEARCH=false`。
- Web 页面、API、本地脚本和 Worker 在默认配置下均拒绝运行。
- 参赛 PPT、Demo、作品简介和公开演示不得展示或宣传该能力。
- 候选人来源应使用虚构 seed 数据、企业已授权简历库、CSV/JSON 或经过合同与权限确认的正式 ATS 接口。

## 重新启用的前置条件

只有同时满足以下条件，部署方才可在独立分支或私有环境自行评估启用：

1. 取得目标平台对具体自动化方式的书面授权。
2. 完成账号权限、服务条款、个人信息处理和数据留存的独立法律审查。
3. 取得候选人数据处理所需的合法基础与告知 / 授权证据。
4. 完成浏览器组件及其传递依赖的软件许可证审计。
5. 由部署方安全负责人批准，并与参赛环境、生产数据和默认镜像隔离。

本文件不提供绕过平台控制、反检测、自动抓取或模拟人工操作的使用指导。
