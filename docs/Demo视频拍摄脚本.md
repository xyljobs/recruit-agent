# 人才决策Agent Demo 视频拍摄脚本

> 目标时长 4 分钟以内 ｜ 1080p 录屏 + 画外音 ｜ 全程使用虚构 seed 数据
> 更新日期 2026-08-16：对齐职位页 Tab 化、关键词提炼、发布版 JD、短名单引导卡等最新功能

## 拍摄前准备

1. 本机 dev（:5000）或部署环境完成迁移、管理员初始化；seed 基线为 7 位虚构候选人 + 2 个职位（智能制造工程师、PLC 电控工程师）。需要干净起点时可在“数据源”页「演示环境管理」卡片一键重置（仅演示组织管理员可见）。
2. 默认使用 `rules_only`。演示 AI 能力时先在“数据源”页完成租户审批（本机 `.env.local` 已置 `AI_EXECUTION_MODE=approved_cloud`），并准备一次关闭审批后的自动降级镜头。
3. `ENABLE_BOSS_SEARCH=false`，不录制外部招聘平台页面或账号。
4. 浏览器只保留应用标签；检查候选人均为虚构数据，关闭桌面通知。
5. 登录后系统默认落在「职位与标准」页（/jobs），第一个镜头直接从职位列表开始。
