# 人才决策Agent Demo 视频拍摄脚本

> 目标时长 4 分钟以内 ｜ 1080p 录屏 + 画外音 ｜ 全程使用虚构 seed 数据

## 拍摄前准备

1. `docker compose up --build`、完成迁移、管理员初始化和 `pnpm seed:demo`。
2. 默认使用 `rules_only`。如演示获批模型，先在“数据源”页完成租户审批，并准备一次关闭审批后的自动降级镜头。
3. `ENABLE_BOSS_SEARCH=false`，不录制外部招聘平台页面或账号。
4. 浏览器只保留应用标签；检查候选人均为虚构数据，关闭桌面通知。
