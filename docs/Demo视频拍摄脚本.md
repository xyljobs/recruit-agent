# 智聘Agent Demo 视频拍摄脚本

> 目标时长 3.5-4.5 分钟 ｜ 1080p 录屏 + 画外音 ｜ 评委视角：30 秒内看懂价值，3 分钟内看完闭环

## 拍摄前准备

1. 环境：`docker compose up --build` 全栈 + `pnpm seed:demo`；另备一份真实 JD 文本与 2-3 份脱敏简历（其中 1 份扫描版 PDF）。
2. AI 模式：演示 `private_endpoint` 或 `approved_cloud` 需先配好 `LLM_API_KEY` 并在"数据源"页完成租户审批；异常降级镜头切回 `rules_only` 演示。
3. 隐私：录屏前确认演示数据均为虚构（seed 数据即虚构）；真实试用数据须打码。
4. 工具：OBS 录屏 + 独立麦克风；浏览器缩放 110%，关闭无关标签与通知。

## 拍摄注意

- 镜头 2 与镜头 7 是差异化核心（AI 执行边界 + 降级），务必完整保留，不剪碎。
- 镜头 5 多模态是赛道明确加分项，扫描件要 visibly 是扫描件（倾斜/印章/灰度）。
- 全程不出现真实候选人姓名与联系方式；Boss 镜头中 HR 扫码环节用字幕"由 HR 本人扫码"带过，不录手机画面。
- 每个镜头单次录完，出错重录整段，避免跳剪暴露剪辑痕迹。
