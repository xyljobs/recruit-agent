# 智聘Agent · 一页纸宣讲（GOAI 无界应用赛道）

## 一句话

智聘Agent 是面向工业制造招聘场景的私有部署决策副驾驶：把已授权简历变成可解释短名单，让 AI 和工具负责整理证据，让 HR 对每个决定负责。

## 为什么值得做

PLC、电气自动化、工业机器人和设备维护岗位的技能证据分散在项目经历中；纯关键词筛选容易漏掉等价经验，完全自动决策又带来隐私、歧视和责任风险。企业真正需要的不是“自动录用”，而是一条可校对、可覆盖、可追责的辅助决策流程。

## 产品闭环

职位标准 → 授权简历导入 → 确定性预筛 / 获批深度分析 → 证据与缺失项 → HR 接受、补充或覆盖 → 沟通 brief → 真实招聘结果 → 校准建议。

当前实现是**单一受控编排工作流**，不是四个自主 Agent。流程步骤由业务状态机预定义；模型不能绕过 AI 网关、租户审批或人工决定节点。

## 差异化

- `rules_only` 默认不调用模型；私有端点或批准云端必须经过部署级和租户级双重审批。
- 姓名、邮箱、电话、当前公司和当前职位加密存储；授权可撤回。
- AI 分数只排序，不自动拒绝、发 Offer 或录用。
- ATS 写回采用事务 outbox 和精确主机白名单；外部招聘平台浏览器自动化不属于参赛交付且默认关闭。

## 已有证据

- IT 单岗位真实授权去标识基线：20 份简历，Spearman **0.706**，强推召回 @5 **2/4**、@10 **4/4**。
- 该结果不外推为制造业效果；制造业三岗位、双标注正式评测方案已随仓库交付，尚待采集真实授权样本。
- TypeScript strict、数据库集成测试、Python Worker 测试、Docker 自托管、Apache-2.0。
