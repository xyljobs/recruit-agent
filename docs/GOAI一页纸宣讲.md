# 智聘Agent · 一页纸宣讲（GOAI 无界应用赛道）

> 用途：初赛宣讲/答辩开场与材料首页。口径与《GOAI参赛说明_无界应用》一致。2026-08。

## The Bet（我们赌什么）

招聘的瓶颈不在"找不到人"，而在"判断太慢、太累、不敢留痕"。我们赌的是：**AI 负责证据与排序，人类保留决策权**，这条路线能在人力密集行业真正落地——因为它同时解决了效率问题和信任问题。智聘Agent 是一款可私有部署的 AI 招聘决策智能体系统，面向**工业制造**与 IT 外包的人才供应链场景，把"JD 解析 → 匹配 → 短名单决策 → 沟通准备 → 结果复盘"做成完整闭环。

## Why Now（为什么是现在）

- 制造业招工潮与 IT 外包交付压力叠加：单岗位人工筛选 4-6 小时，有效匹配率仅 40-50%（对 5 家人力外包公司 HR 的访谈测算值，实测校准机制已上线）。
- 大模型能力到位但信任缺位：企业不敢把简历交给公有云 SaaS。《个人信息保护法》第 24 条对自动化决策的约束，让"全自动招聘"在法律上走不通——**人机分工不是妥协，是唯一合规的产品形态**。
- 私有部署成本大幅下降：Next.js + Supabase（可 Docker 自托管）+ Python Worker，一台 Mac mini 即可承载全栈。

## 闭环与智能体拓扑（任务闭环七要素全覆盖）

四个协作智能体 + 一个人类决策节点：JD 解析 Agent（结构化提取 + 隐含需求识别）→ 匹配 Agent（规则预筛 + LLM 深度分析，输出证据/缺失信息/版本化置信度）→ 沟通 Agent（本地知识库驱动个性化 brief，仅在人工"已接受"后生成）→ 数据工具 Agent（Boss 搜索 / 简历批处理 / ATS 写回，任务队列 + 租约 + 状态机）。HR 在短名单上逐条接受/覆盖并留痕；真实招聘结果经 outcomes/calibration 回流校准评分权重。异常处理贯穿全程：`error`/`login_required` 状态恢复、rules_only 自动降级、出站主机白名单。

## 差异化：把 AI 关进制度的笼子

`AI_EXECUTION_MODE` 三档执行边界：`rules_only`（默认，不调用任何模型）→ `private_endpoint`（企业私有端点）→ `approved_cloud`（经批准的外部端点，**仅发送去标识化载荷**）。部署模式只是能力上限，每个租户还须管理员在数据源页逐项审批。这不是配置项，是产品主轴——评委可在 Demo 中亲眼看到审批与降级镜头。

## 证据（可验证价值）

- **真实数据评测**：20 份真实授权简历（去标识 R01-R20）+ 资深 IT 招聘方三档标注，规则评分器与人工排序 **Spearman 秩相关 0.706**，**强推候选人零漏出前 10（召回 4/4）**。分歧样本分析印证设计：AI 只排序、不决策。报告与基准文件随仓库交付，`pnpm eval:match` 一键复现。
- **真实运行痕迹**：Boss 搜索任务队列 9 条真实任务的状态机日志（认领/租约/失败重试/报告回写）见 `docs/evidence/`。
- **工程质量**：74+ 单元测试 + 数据库集成测试（迁移幂等/RLS/决策流程/100 候选人性能包络）+ Python Worker 测试，GitHub Actions CI 常绿；TypeScript strict，Apache-2.0。

## 合规（详见《数据合规与隐私白皮书》）

姓名/联系方式等五字段 AES-256-GCM 加密 + HMAC 索引；候选人知情授权、可撤回（最强清理 + 回执）、可拒绝自动化匹配；不做跨企业数据聚合，数据不出部署域；招聘平台接入遵循"人授权、本地跑、可审计"。

## 可复制性

`docker compose up --build` 起全栈，三条命令初始化演示环境；知识库为可插拔 Markdown（IT 技能图谱已含制造业技能组）；换行业只需换知识库与 seed。
