# 人才决策Agent · 初赛作品简介（≤500 字）

人才决策Agent 选择“AI+工业制造”的人才供应链细分场景——与赛题工单调度 Agent“按人员技能分派”同构，是其上游的“技能证据→人岗匹配”环节，服务 PLC、电气自动化、工业机器人、设备维护等岗位招聘。它不是自动录用系统，而是一款可私有部署的招聘决策副驾驶：将“职位标准、授权简历导入、可解释排序、人工短名单决策、沟通准备、结果复盘”组织为可审计闭环。当前实现采用单一受控编排工作流，业务状态机确定步骤；规则能力默认可用，模型仅在部署级与租户级双重批准后调用，云端只接收去标识化能力画像。敏感字段加密，授权可撤回，AI 只排序，拒绝与录用始终由人决定。参赛演示仅使用虚构种子数据、企业授权简历或正式 ATS/CSV 接口，外部招聘平台浏览器自动化默认关闭且不属于参赛交付。现有可复现证据为 IT 单岗位 20 份去标识简历基线：Spearman 0.706，强推召回@10 为 4/4；该结果不外推为制造业效果。项目以 Apache-2.0 开源，支持 Docker 自托管；制造业三岗位 58 份真实授权简历评测已完成：HR 与 AI 标签一致率 34.5%、加权 κ=0.280，据此定位为“提供证据、人工决策”，不宣称专家真值。
