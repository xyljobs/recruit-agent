# 智聘Agent · 初赛作品简介（正文 461 字，≤500 字要求内）

智聘Agent，所选行业赛题：AI+工业制造（人才供应链细分场景）。目标用户：制造业与IT外包企业的招聘团队。核心问题：单岗位人工筛简历4-6小时、有效匹配率仅40-50%，HR读不懂PLC/工业机器人技能栈，简历数据散落且授权无留痕。解决方案：可私有部署的招聘决策智能体系统，将"JD解析→候选人匹配→短名单决策→沟通准备→结果复盘"做成完整闭环；四个协作智能体负责证据与排序，人类保留决策权。创新点：AI执行边界三档治理（rules_only默认/private_endpoint/approved_cloud），云端模型须部署+租户双重审批且仅发送去标识化载荷；敏感字段AES-256-GCM加密、授权可撤回；扫描版简历视觉结构化（多模态、默认关闭）。开放/复用价值：Apache-2.0开源，Docker一键部署，行业知识库为可插拔Markdown，可复制至任一人力密集行业。当前进展：真实数据评测规则评分与人工排序Spearman 0.706、强推召回@10=4/4；74+单测与CI齐备；私有部署演示环境已运行。
