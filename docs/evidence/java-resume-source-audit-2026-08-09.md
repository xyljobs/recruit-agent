## 五、完成双标注所需动作

1. HR 和 Java 业务专家分别填写匿名双人标注模板，互不查看答案和系统排序。
2. 第三人处理标签或硬性淘汰判断不一致的样本，保留两份原始标注。
3. HR 完成 6 条年限差异复核。
4. 使用 `pnpm eval:import-annotations` 生成私有 annotated benchmark，再运行 `pnpm eval:match`。
5. 对外只更新汇总指标，不提交原始 PDF、身份映射、标注者姓名或简历证据原文。

## 六、适用边界
