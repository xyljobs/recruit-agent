## 演练挖出并修复的全新安装回归（共 5 项）

1. **users 列级 GRANT 缺 `mfa_enabled`**：`/api/auth/me` 的 select 列表含该列，全新部署首次加载 42501，页面卡"加载中"。修复：`scripts/migrate.sql` GRANT 清单补列。DB 集成测试走 service_role，无法发现此类缺口——只有真实租户用户能暴露。
2. **Docker Worker 崩溃循环**：`worker:build` 用 tsup 默认配置把 dependencies 当 external，standalone 镜像无 node_modules，worker 启动 `Cannot find module 'zod'`。修复：新增 `tsup.workers.config.ts`（`noExternal: [/.*/]`），`worker:build` 改用该配置。
3. **Supabase 新版密钥兼容坑**：`add-new-auth-keys.sh` 写入 `JWT_JWKS` 后 PostgREST 改用非对称 JWKS 校验，而应用 RLS 令牌仍以 legacy `JWT_SECRET` HS256 签名，表现为登录后 401/"用户不存在"。处置：演练环境删除 `JWT_JWKS` 行回退；`docs/Mac-mini-M4数据库安装步骤.md` 已加告警。
4. **速率限制 RPC 白名单缺 8 个 scope**：`consume_api_rate_limit` 的 CASE 白名单未含 `shortlists:read/create/qualify/decision`、`outcomes:create`、`match:single`、`candidates:search`、`communication-briefs:create`，导致短名单/结果录入/搜索/话术等接口全新安装即 500。修复：`scripts/migrate.sql` 两个 CASE 分支补齐。
5. **seed 职位缺 `activated_at`**：批量匹配 RPC 的 active 校验要求 `activated_at IS NOT NULL`，种子职位未写入导致演示流程首跑 404。修复：`scripts/seed-demo.ts` 插入时带 `activated_at`。
