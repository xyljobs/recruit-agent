# 制造业岗位匹配正式评测方案

> 状态：预注册方案，尚未完成数据采集；本文件不包含制造业效果结论。

## 一、目标

验证 explainable-base-v1 在制造业技术岗位上是否足以作为“人工复核前的证据排序工具”，并识别行业技能同义词、证据缺失和地域 / 班次等硬约束的失效模式。

## 二、样本与岗位

| 岗位 | 最低样本 | 重点能力 |
|---|---:|---|
| PLC / 电气自动化工程师 | 20 份授权简历 | 西门子 / 三菱 PLC、组态、伺服、变频器、现场调试 |
| 工业机器人工程师 | 20 份授权简历 | FANUC / ABB / KUKA、示教、离线编程、节拍优化、安全规范 |
| 设备维护工程师 | 20 份授权简历 | TPM、预防性维护、故障诊断、机械 / 电气图纸、备件管理 |

要求至少 60 份去标识化真实授权简历。每个岗位至少包含明确合格、边界样本和不合格样本，禁止只采集“容易命中”的正例。

## 三、标注

1. 每份简历由 2 位互相独立的标注者评审：1 位制造业招聘 HR、1 位对应岗位业务专家。
2. 在查看系统分数前完成强推 / 可谈 / 不推三档标注，并记录硬性淘汰项、证据出处和待确认问题。
3. 分歧样本由第三人仲裁，但同时保留两位原始标注，用于计算加权 Cohen’s kappa。
4. 所有姓名、联系方式、公司名和可识别项目名在进入基准文件前去标识化。

## 四、固定指标

- Spearman 排序相关系数。
- NDCG@10。
- 强推召回率 @5 / @10。
- Precision@5。
- 双标注者加权 Cohen’s kappa。
- 硬性条件误放数、强推漏出数及逐条分歧原因。

## 五、团队内部验收门槛

以下为项目自定门槛，不是主办方标准，也不代表已经达到：

- 三岗位合并 Spearman ≥ 0.65。
- 每个岗位强推召回率 @10 ≥ 0.80。
- 不得因姓名、性别、年龄等与岗位无关信息改变分数；发现即作为 P0 缺陷处理。
- 所有进入 Top 10 的候选人必须能够展示证据或明确标注“信息缺失”。

未达门槛时只报告原始结果和分歧，不调低门槛；权重调整必须生成新版本并在独立留出集上复测。

## 六、执行与发布

1. 冻结代码版本、评分器版本和岗位卡片。
2. 完成双盲标注并锁定文件哈希。
3. 运行与 `pnpm eval:match` 等价的评测脚本，保存原始输出。
4. 公开汇总指标、岗位级指标、标注一致性和去标识化分歧案例。
5. 不公开原始简历；未经候选人和数据控制方许可，不将基准文件提交到公开仓库。
