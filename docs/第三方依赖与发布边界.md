# 第三方依赖与发布边界

> 版本：2026-08 ｜ 本清单用于参赛披露，不替代正式开源许可证审计或法律意见。

## 一、权威清单

- Web / TypeScript 直接与传递依赖：`package.json`、`pnpm-lock.yaml`。
- Python 直接与传递依赖：`assets/pyproject.toml`、`assets/uv.lock`。
- 容器镜像与系统包：`Dockerfile`、`docker-compose.yml`、`docker-compose.test.yml`。

发布前以锁文件中的确切版本重新生成 SBOM 和许可证报告；本文只说明当前直接依赖分组与需要人工复核的边界。

## 二、参赛主链路依赖

| 分组 | 主要包 | 用途 | 发布检查 |
|---|---|---|---|
| Web 框架 | Next.js、React、React DOM、TypeScript | 页面、API 与类型系统 | 保留上游版权和许可证文本 |
| UI | Radix UI、Tailwind CSS、lucide-react、Recharts、Sonner | 组件、样式、图标与图表 | 检查图标和字体是否来自允许再分发来源 |
| 数据 | `@supabase/supabase-js`、pg、Drizzle、xlsx | PostgreSQL / Supabase、导入导出 | 生产启用 xlsx 前复核其当前分发条款 |
| 安全 | jose、bcryptjs、cryptography | JWT、密码哈希、加密 | 不分发密钥；记录算法与轮换策略 |
| AI | openai SDK | OpenAI 兼容端点 | SDK 开源许可不等于模型服务或输入数据已获授权 |
| 文档解析 | pdfplumber、PyMuPDF | 本地 PDF 文本与页面处理 | **PyMuPDF 为 AGPL / 商业双许可，发布前必须确定适用许可；不满足时替换或购买许可** |
| Worker / HTTP | requests、supabase-py、python-dotenv | 异步任务与配置 | 锁定版本并保留许可证清单 |

## 三、外部服务

| 服务 | 默认状态 | 数据边界 |
|---|---|---|
| OpenAI 兼容模型端点 | 关闭（`rules_only`） | 私有端点或批准云端；云端只发送去标识化能力画像 |
| 扫描件视觉模型 | 关闭 | 可能接收原始简历图像，必须另行授权和供应商评估 |
| ATS / webhook | 关闭 | 仅精确 HTTPS 主机白名单；事务 outbox 异步写回 |
| 钉钉 MCP | 可选、关闭 | 由部署方自有应用和权限决定，不影响主流程 |

## 四、参赛排除项

`assets/boss.py`、`assets/boss_worker.py` 及相关页面 / API 为历史实验性浏览器自动化，不属于 GOAI 参赛交付：

- `.env.example` 默认 `ENABLE_BOSS_SEARCH=false`。
- Web 页面与 API 返回 404；本地命令行返回禁用错误。
- Demo、PPT、作品简介与参赛说明不得展示或宣传该能力。
- `cloakbrowser`、`pywebview` 等仅由该排除项使用，不应进入参赛运行镜像或部署清单。
- 若未来确需启用，必须先取得目标平台书面授权，完成服务条款、个人信息、账号权限和软件许可证独立审查。

## 五、发布门禁

- [ ] 从锁文件生成 CycloneDX 或 SPDX SBOM，并随 Release 保存
- [ ] 对每个直接和传递依赖记录版本、许可证、版权声明和源地址
- [ ] 解决 PyMuPDF 的 AGPL / 商业许可选择
- [ ] 确认容器基础镜像及系统包许可证
- [ ] 确认演示图片、字体、图标、视频音乐和截图拥有使用权
- [ ] 参赛镜像未安装、未启动浏览器自动化排除项
- [ ] 模型、ATS、MCP 与 webhook 的服务条款和数据处理协议由部署方确认
